Studio now checks for releases every 30 minutes and has a Check for updates button. Release checks no longer stay on yesterday's version, and connection or rate-limit errors appear in the sidebar.

## Changes

- Reduce the shared release cache from 24 hours to 30 minutes, matching the background check interval.
- Refresh older daily caches automatically while preserving conditional requests, offline metadata, and rate-limit backoff.
- Add Check for updates to the sidebar footer, including when the current installation cannot install binary updates.
- Display discovery failures instead of hiding the update control while Studio is idle.
- Keep downloading and installation separate. Downloading an update does not install it or restart your project.
- Publish selection state atomically so agents and other readers never see a partially written JSON file.

## Updating from an older Studio

If the update control is missing, run `framio upgrade --check` in your terminal. Then return to Studio and use Update available to download v0.0.11. Use Install update when you are ready to restart the current project.

If GitHub reports a rate limit, wait for it to reset before checking again.
