The Framio skill now describes what is available instead of prescribing a workflow. Agents get a catalog of frames, project files, commands, and included components, and decide for themselves when to explore directions, review screenshots, or check in.

## Changes

- Rewrite the agent skill as a catalog of frame metadata, project files, commands, components, and installed packages, with system contracts stated as facts.
- Remove the mandatory process: question limits, a fixed number of directions, the direction checkpoint, and review loops.
- Replace the 31-pattern copy checklist with short copy preferences about truthful claims, product tone, and punctuation.
- Make the evidence record optional. The skill documents its fields and revision-safe write contract without requiring a review cadence.
- Remove the RareUI registry from new projects.
- Update the README, docs, and landing page to match.

## Existing projects

Binary updates do not change a project's skill files. Run `framio init` in a new project to get the new skill, or copy `.claude/skills/framio` and `.agents/skills/framio` from a fresh project. Existing `components.json` files keep any registries they already list.
