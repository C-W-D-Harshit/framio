Update Framio with one command. Run framio update to check, download, verify, and install the latest release. Framio upgrade works as an alias, and running projects tell you when they need a restart.

## Changes

- Make `framio update` the primary CLI update command, with `framio upgrade` as an alias.
- Complete checking, downloading, verification, and installation in one invocation without prompts, including in scripts.
- Resume verified staged updates and retry installation without requiring network access.
- Add `--status` for read-only inspection and retain `--check`, `--download`, `--install`, and `--rollback` for separate actions.
- Show progress and the installed version. Running projects stay available and are listed for restart after you save your work.
- Keep Studio's separate download and install controls.

## Updating from an older version

Versions before v0.0.12 use `framio upgrade --download` followed by `framio upgrade --install`. Restart running projects after saving. From v0.0.12 onward, use `framio update`.
