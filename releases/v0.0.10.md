Framio now runs on Windows x64. The agent skill is focused on the canvas: it no longer tells your agent which templates, component libraries, or outside design skills to use, so you can bring your own.

## Changes

- Add Windows x64 support. Install with `irm https://framio.design/install.ps1 | iex` in PowerShell on Windows 10 version 1809 or later. Installation adds `~/.framio/bin` to your user PATH without administrator access.
- Bound process tree cleanup when the canvas stops and report cleanup failures.
- Remove the `framio references` command and its curated Tailark, Axis, and Notio reference catalog.
- Remove library, icon set, and outside design skill guidance from the agent skill. Remove the bundled microinteractions skill.
- Stop adding Tailark registries to new projects. shadcn/ui stays the base component set.
- Existing evidence files that contain reference shortlists still load. Reviews show as outdated once because the design guidance changed.

Project update required: Binary installation does not refresh existing project skills. For an existing project, copy `.agents/skills/framio/` and `.claude/skills/framio/` from a temporary project initialized with v0.0.10, after reviewing any local skill changes. Delete `references/libraries.md` and `references/skills.md` from both skill folders if they remain. Keep the existing `.framio/` directory, themes, dependencies, and designs.
