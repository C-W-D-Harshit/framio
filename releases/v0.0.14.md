Framio now reports anonymous usage and errors so problems users hit can be found and fixed. Reports never include designs, comments, or file paths. Run `framio telemetry off` or set `FRAMIO_TELEMETRY=0` to disable it. Framio is now labeled as alpha.

## Changes

- Add anonymous telemetry to the CLI, local server, and canvas. Events are tied to a random installation ID stored in `~/.framio/telemetry.json`.
- Report CLI failures, server errors, failed canvas and comment saves, update failures, and frames that fail to build or run.
- Add `framio telemetry status`, `framio telemetry on`, and `framio telemetry off`. `FRAMIO_TELEMETRY=0` and `DO_NOT_TRACK=1` override the saved choice. A one-time notice explains this on first run.
- Exclude designs, page and frame names, comment text, element text, file paths, and network addresses. Session recording stays off.
- Ship source maps with the binary so error reports point to source lines. The binary is about 9 MB larger.
- Label Framio as alpha in the canvas, CLI, installers, and skill.

## Existing projects

Binary updates do not change a project's skill files. The alpha label in the skill is cosmetic, so existing projects need no changes.
