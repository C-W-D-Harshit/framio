Run Framio on a VM and open its local, network, or Tailscale URL from your main computer. Headless startup keeps the canvas usable without a desktop browser, and the canvas and CLI can now share downloads, installation, and update recovery.

## Changes

- Listen on all IPv4 interfaces by default and print local, network, and available Tailscale URLs. Use `--host 127.0.0.1` for local-only access.
- Skip automatic browser launch in SSH, CI, and headless Linux sessions. If Chromium is unavailable, show feature errors while keeping live previews usable.
- Support clipboard actions over remote HTTP and allow update actions from advertised server origins while rejecting foreign browser origins.
- Preserve the listen address, port, and project identity through server restart and recovery.
- Add shared update downloads, checksum verification, installation, rollback, and recovery to the canvas and CLI. Binary updates do not change project skills, dependencies, themes, or designs.
- Show setup progress, subprocess diagnostics, and retry instructions in the CLI.

Anyone who can reach the canvas port can edit it. Use a trusted network, firewall rules, and Tailscale access rules. Tailscale encrypts traffic through its tunnel. HTTPS requires a separate setup, such as Tailscale Serve.
