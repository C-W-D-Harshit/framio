You can now make quick edits directly on the canvas. Let your agent design, then fix a word, resize a card, or reorder a list yourself without writing a prompt. Every edit is written back to the frame's TSX source as a minimal change.

## Changes

- Click an element in a frame to select it. Double-click text to edit it, press Enter to save and Escape to cancel.
- Drag the handles on a selected element to resize it. Sizes snap to 4px. Hold Shift for free sizing.
- Drag a selected element to reorder it among its siblings.
- Press Delete to remove an element and ⌘D to duplicate it. ⌘Z and ⇧⌘Z undo and redo, restoring the file exactly.
- Edits on a component call site, such as a `Button`, change the page that uses it, not the shared component.
- Text, classes, and lists computed in code are locked. The inspect panel explains why.
- If your agent changes the file while you edit, your edit is refused and the agent's version wins.

## Existing projects

Quick edits work in existing projects without changes. New projects get a skill that asks the agent to write text and classes as literals, so more elements are editable. Existing projects keep their current skill, so expect more locked elements there.
